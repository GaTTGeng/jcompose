# Support

jcompose is an open-source Java project maintained through GitHub.

## Questions and usage help

Use GitHub Discussions for usage questions, design discussion, and roadmap topics:

https://github.com/GaTTGeng/jcompose/discussions

## Bugs and compatibility gaps

Open an issue with a minimal Compose file, Docker Engine and Docker Compose versions, jcompose commit or package version, expected behavior, actual behavior, and relevant logs:

https://github.com/GaTTGeng/jcompose/issues

For compatibility reports, describe the behavior of Docker Compose that should be matched. ComposeSharp is the feature synchronization source, not the compatibility authority.

## Security issues

Do not open public issues for vulnerabilities. Follow [SECURITY.md](SECURITY.md).
